Notification Link

Easily navigate to related documents directly from Odoo notifications

Module Overview

The Notification Link module enhances Odoo's native mail and notification system by adding a convenient "View Record" button. This feature ensures that users can quickly redirect to the associated document directly from their notification tray, effectively saving time and boosting navigation efficiency.

Key Features & Benefits

  • Instantly access related records from the standard Odoo notification pop-ups.
  • Eliminates the need to manually search for the document mentioned in the notification.
  • Improves overall user experience and workflow efficiency.
  • Seamlessly integrates with Odoo's native mail and discussion app.
  • Ready to use out of the box with zero complex configuration required.

Screenshots

How to Use / Workflow

  1. Install the Notification Link module from the Apps menu.
  2. The module is ready to use immediately with zero configuration required.
  3. Trigger any action in Odoo that generates a notification linked to a document.
  4. Notice the new "View Record" button on the notification pop-up.
  5. Click the button to automatically redirect your view to the associated record.

Why Choose This Module?

Ideal for almost every Odoo user facing the hassle of manually searching for a record mentioned in a notification popup. Notification Link significantly improves database navigation and user experience. Suitable for sales teams, accountants, inventory managers, and anyone handling documents in Odoo.

It integrates smoothly with the native mail app and notifications system, providing immediate value through faster and more direct access to system records.
